### 4. How the 5-Second Timer Works

```js
useEffect(() => {
  if (phase !== 'memorise') return;

  // Start a 1-second interval
  timerRef.current = setInterval(() => {
    setCountdown(prev => {
      if (prev <= 1) {
        clearInterval(timerRef.current);  // stop the interval
        setAnswerStart(Date.now());        // record when question starts
        setPhase('question');              // advance phase
        return 0;
      }
      return prev - 1;                    // decrement countdown
    });
  }, 1000);

  return () => clearInterval(timerRef.current); // CLEANUP
}, [phase]);
```

- The `return` at the end is a **cleanup function** — React calls it when the component unmounts or the effect re-runs. This prevents the interval from leaking if the user taps "? Home" mid-game.

Simple subtraction. `Date.now()` returns milliseconds since epoch. The difference divided by 1000 gives whole seconds.

They are selected using a helper function called `pickRandom` which takes an array, shuffles it using the Fisher-Yates method, and slices the required number of objects:
```javascript
function pickRandom(arr, count) {
  // Shallow-copy so we don't mutate the original pool
  const shuffled = [...arr].sort(() => Math.random() - 0.5);
  return shuffled.slice(0, count);
}
```
